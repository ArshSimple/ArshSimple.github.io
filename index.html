FaceChain — Decentralized Auth

View Repository

I was awarded Grade O (Outstanding) for building a decentralized authentication system merging facial recognition and blockchain technology. I led the requirement analysis, design planning, and full technical implementation.

Executive Summary (Introduction)

I designed FaceChain to eliminate single-point-of-failure credential databases by pairing real-time facial landmark extraction with blockchain smart contract verification—providing tamper-proof identity validation.

Challenges & Problem Statement

Traditional password and centralized biometric servers are vulnerable to credential stuffing and database breaches. I solved this by storing cryptographic identity proofs on a decentralized ledger.

User Journey & Verification Pipeline

1. Camera captures live facial frame → 2. 128-D facial encoding extracted → 3. Smart contract verifies wallet & identity state → 4. Immutable session token granted.
